# 🎯 Roletas - Instruções de Uso

## 🚀 Como Executar o Projeto

### 1. Instalação
```bash
# Instalar dependências
npm install
```

### 2. Desenvolvimento
```bash
# Iniciar servidor de desenvolvimento
npm run dev

# Acessar no navegador
http://localhost:5173
```

### 3. Build de Produção
```bash
# Gerar build otimizado
npm run build

# Visualizar build
npm run preview
```

## 🎮 Como Usar o Site

### Roletas Pré-definidas
1. **Acesse a página inicial**
2. **Escolha uma categoria** (Comida, Números, Sim/Não, etc.)
3. **Clique em "Girar Roleta"**
4. **Veja o resultado** destacado

### Roletas Personalizadas
1. **Clique em "Criar Personalizada"**
2. **Digite um nome** para sua roleta
3. **Adicione opções** (mínimo 2, máximo 20)
4. **Escolha cores** para cada opção
5. **Salve a roleta**
6. **Use sua roleta** criada

### Gerenciar Roletas Salvas
1. **Acesse "Suas Roletas Personalizadas"**
2. **Visualize todas** as roletas criadas
3. **Edite ou exclua** conforme necessário

## 🔍 Solução de Problemas

### Roleta Não Gira
- Verifique se há pelo menos 2 opções
- Recarregue a página
- Limpe o cache do navegador

### Roletas Personalizadas Sumiram
- Verifique se o localStorage está habilitado
- Não use modo incógnito para criar roletas
- Faça backup exportando suas roletas

### Anúncios Não Aparecem
- Verifique se aceitou os cookies de anúncios
- Aguarde a aprovação do Google AdSense
- Verifique sua conexão com a internet

### Site Lento
- Verifique sua conexão
- Limpe o cache do navegador
- Feche outras abas desnecessárias
